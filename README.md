# 基调 TONE

面向使用编码助手的开发者的设计规范工作台。

## 运行

`npm install`，然后 `npm run dev`。构建：`npm run build`。类型检查：`npx tsc --noEmit`。

## 功能

16 套清爽界面配色、配色灵感页面实时试色、12 套数据可视化色板、9 个语义颜色，字体与层级比例、间距密度、圆角与阴影；业务、组件、内容和数据图表预览；柱状图、折线图、饼状图、桑基图规范；桌面和窄屏预览；文字与图形对比度提示；一键下载和复制 Markdown。草稿仅保存到当前浏览器的 localStorage，旧版预设草稿会迁移到对应的新版配色。

`lib/design.ts` 是预览与导出的共同数值来源。`app/studio.tsx` 是客户端编辑界面。预览中的项目和指标均为演示内容。

WebMCP 为可选增强：环境支持时注册读取规范和应用配色两个工具。不依赖该接口完成正常操作；本次没有支持该接口的验证环境，未声明浏览器端 WebMCP 已验证。
